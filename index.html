YouTube API Settings

API Configuration
API key disimpan hanya di browser ini (localStorage). Batasi key untuk YouTube Data API v3 dan domain aplikasi Vercel Anda.
Cara mendapatkan YouTube Data API v3 secara gratis
  • Buka Google Cloud Console dan buat/pilih project.
  • Buka APIs & Services → Library, cari YouTube Data API v3, lalu klik Enable.
  • Buka APIs & Services → Credentials → Create Credentials → API key.
  • Salin API key ke field di atas, lalu klik Save API Key.
  • Setelah berhasil dites, batasi key hanya untuk YouTube Data API v3 dan HTTP referrer domain Vercel aplikasi ini.
